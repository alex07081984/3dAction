# 3D Action

Стартовый проект мобильного 3D-экшена от третьего лица на **Godot 4** и **GDScript** (без C#).
Рассчитан на Android и сенсорное управление, но работает и на ПК с клавиатурой или геймпадом.

Проверен на Godot **4.4.1** и **4.7.2**. Рендер — *Compatibility* (OpenGL ES 3): он работает на большинстве телефонов, включая слабые.

## Что уже есть

- **Игрок**: бег относительно камеры, прыжок (с «койот-таймом» и буфером нажатия), рывок с неуязвимостью, комбо из трёх ударов мечом, автонаведение удара на ближайшего врага, мигание и отброс при получении урона.
- **Камера**: от третьего лица на SpringArm3D (не проходит сквозь стены), вращается свайпом по экрану, тряска при ударах.
- **Враги**: преследуют игрока, перед ударом заметно замахиваются и светлеют — есть время уйти рывком. Удар сбивает замах, а враги не слипаются в кучу.
- **Волны**: в каждой следующей волне врагов больше и они быстрее, между волнами игрок лечится.
- **Интерфейс**: здоровье, номер волны, пауза, экран поражения с рестартом.
- **Сенсорное управление**: плавающий джойстик слева, кнопки «Удар», «Прыжок» и «Рывок» справа, мультитач. Кнопка «Назад» на Android ставит игру на паузу.

## Как открыть на телефоне

1. Скачайте ZIP проекта: на GitHub **Code → Download ZIP**.
2. В Godot на телефоне, в менеджере проектов: **Import** → выберите скачанный `.zip` → **Import & Edit**.
3. Нажмите ▶ (Run Project) — игра запустится прямо на телефоне.

## Управление

| Действие | Телефон | Клавиатура | Геймпад |
|---|---|---|---|
| Бег | джойстик слева | WASD / стрелки | левый стик |
| Камера | свайп по экрану | Q / E, правая кнопка мыши | правый стик |
| Удар (комбо) | «Удар» | J | X |
| Прыжок | «Прыжок» | Пробел | A |
| Рывок | «Рывок» | Shift / K | B |
| Пауза | II / «Назад» | Esc / P | Start |

## Структура

```
scenes/main.tscn      — уровень, точки появления врагов, игрок, HUD
scenes/player.tscn    — игрок и камера
scenes/enemy.tscn     — враг
ui/hud.tscn           — интерфейс и сенсорные кнопки
scripts/player.gd     — движение, рывок, комбо, здоровье
scripts/camera_rig.gd — камера от третьего лица
scripts/enemy.gd      — ИИ врага
scripts/game.gd       — волны, рестарт
scripts/hud.gd        — интерфейс, пауза
scripts/touch/        — сенсорный джойстик и кнопки
tests/smoke_test.gd   — автопроверка без окна
```

## Как настраивать

Почти все параметры — это `@export`-переменные, их можно менять в **Инспекторе** без правки кода:

- **Player** (в `player.tscn`): скорость, прыжок, рывок, здоровье, радиус автонаведения.
- **Enemy** (в `enemy.tscn`): здоровье, скорость, длительность замаха, урон.
- **Main** (корень `main.tscn`): размер волн, лечение между волнами.
- **CameraRig**: дистанция камеры, чувствительность свайпа, наклон.

Удары комбо (урон, тайминги, отброс) описаны в константе `COMBO` в начале `scripts/player.gd`.

Уровень собран из `CSGBox3D` с включённой коллизией: двигайте и меняйте размер коробок прямо в редакторе — столкновения подстроятся сами.

Слои физики: 1 — мир, 2 — игрок, 3 — враги.

## Сборка APK

В проекте уже есть пресет экспорта **Android** (`export_presets.cfg`). Нужно скачать шаблоны экспорта: **Editor → Manage Export Templates → Download**. Затем **Project → Export → Android**. Перед публикацией замените `package/unique_name` (`com.example.action3d`) на свой.

## Автопроверка (на ПК)

```
godot --headless --path . -s res://tests/smoke_test.gd
```

Тест загружает уровень, имитирует касания джойстика и кнопок и проверяет движение, камеру, урон, комбо, паузу, волны и рестарт.
