# 3D Action

Мобильный шутер от третьего лица на **Godot 4** и **GDScript** (без C#).
Рассчитан на Android и сенсорное управление, но играется и на ПК с клавиатурой или геймпадом.

Проверен на Godot **4.4.1** и **4.7.2**. Рендер — *Compatibility* (OpenGL ES 3): он работает на большинстве телефонов, включая слабые.

## Что есть в игре

- **3 линейных уровня:**
  - **Подземка** — коллекторы, насосная, отстойник, шлюз.
  - **Метро** — вестибюль, эскалатор, станция с поездом, тоннель, станция «Конечная».
  - **Небоскрёб** — скай-лобби, офисы, серверная, крыша с вертолётной площадкой.
- **Враги стоят на постах.** На каждом уровне 2–3 места с волнами: проходы закрываются, пока не отобьётесь.
- **Оружие:**
  - пистолет с бесконечными патронами;
  - Desert Eagle — мощный, хедшот убивает сразу;
  - дробовик — в упор разрывает тело на куски.
- **Хедшоты.** Голова отлетает, из шеи бьёт фонтан крови. Помощь в прицеливании «доводит» выстрел, а прицел краснеет на враге.
- **Враги:**
  - стрелок — перед выстрелом наводит красный лазер, значит, пора уйти рывком;
  - псих с битой — бежит на вас;
  - громила — много здоровья, стреляет очередями.
- **Подбираемое:** аптечки, патроны и оружие; враги иногда их роняют.
- **Главное меню, выбор уровней и рекорды.** Сохраняются рекорды по времени, убийствам и хедшотам.
- **Настройки:** чувствительность, громкость, помощь в прицеливании, автоогонь, тени.
- **Звуки и эффекты:** звуки синтезированы, есть вспышки выстрелов, трассеры, кровь, искры, следы от пуль.

## Как открыть на телефоне

1. Скачайте ZIP проекта (на GitHub: **Code → Download ZIP**).
2. В Godot на телефоне, в менеджере проектов: **Import** → выберите `.zip` → **Import & Edit**.
3. Нажмите ▶ — запустится главное меню.

## Управление

| Действие | Телефон | Клавиатура | Геймпад |
|---|---|---|---|
| Бег | джойстик слева | WASD | левый стик |
| Прицел | свайп по экрану или по кнопке «Огонь» | стрелки, правая кнопка мыши | правый стик |
| Огонь | «Огонь» (держать) | F / J | RT |
| Перезарядка | «Заряд» | R | X |
| Смена оружия | кнопка с названием оружия | Q / Tab | Y |
| Рывок (неуязвимость) | «Рывок» | Shift / K | B |
| Прыжок | «Прыжок» | Пробел | A |
| Пауза | II / «Назад» | Esc / P | Start |

## Структура

```
scenes/main_menu.tscn        — главное меню
scenes/levels/               — три уровня
scenes/player.tscn           — игрок и камера из-за плеча
scenes/enemies/              — стрелок, псих, громила
ui/hud.tscn                  — интерфейс и сенсорные кнопки
ui/settings_panel.tscn       — настройки
weapons/*.tres               — параметры оружия
materials/*.tres             — материалы уровней
scripts/autoload/game.gd     — уровни, прогресс, настройки, сохранение
scripts/autoload/audio.gd    — звуки
scripts/autoload/fx.gd       — кровь, искры, трассеры, следы
scripts/blocky_character.gd  — блочная модель: анимация, хедшоты, разрыв на куски
scripts/player.gd            — стрельба, помощь в прицеливании, перезарядка, рывок
scripts/enemy.gd             — ИИ врагов
scripts/wave_zone.gd         — места с волнами
scripts/level.gd             — логика уровня, статистика
tests/                       — автопроверка
tools/                       — генераторы звуков и текстур (Python, для ПК)
```

## Как настраивать

- **Оружие** — откройте `weapons/pistol.tres`, `deagle.tres` или `shotgun.tres`. В Инспекторе меняются урон, разброс, скорострельность, магазин, перезарядка, отдача и порог разрыва тела (`gib_damage`).
- **Враги** — `scenes/enemies/*.tscn`: здоровье, скорость, урон, время прицеливания, точность и шанс выпадения предметов. Цвета одежды задаются в узле **Model**.
- **Уровни.** Стены и пол собраны из `CSGBox3D` с коллизией. Двигайте их и меняйте размер прямо в редакторе.
  - Чтобы добавить врага, перетащите сцену из `scenes/enemies/` в узел **Enemies**.
  - У места с волнами (узел **Zone…**) настраиваются число волн и врагов. Точки появления лежат в **Spawns**, закрывающиеся проходы — в **Barriers**.
- **Список уровней** задан в `scripts/autoload/game.gd` (константа `LEVELS`).

**Слои физики:** 1 — мир, 2 — игрок, 3 — враги, 4 — обломки тел.

## Сборка APK

В проекте есть пресет экспорта **Android**.
1. Скачайте шаблоны экспорта: **Editor → Manage Export Templates → Download**.
2. Соберите APK: **Project → Export → Android**.

Перед публикацией замените `package/unique_name` (`com.example.action3d`) на свой.

## Автопроверка (на ПК)

```
godot --headless --path . -s res://tests/smoke_test.gd
```

Тест проходит 56 проверок:
- все уровни загружаются, маршрут от старта до выхода проходим;
- стрельба, хедшоты и разрыв тела дробовиком работают;
- враги дают отпор;
- подбор предметов, сенсорные кнопки и джойстик работают;
- места с волнами работают, выход завершает уровень;
- пауза, смерть и рестарт работают.
